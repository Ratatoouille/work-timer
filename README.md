# work-timer

TUI-калькулятор времени окончания рабочего дня. Вводишь время начала и сколько осталось работать — получаешь время когда можно уйти, с учётом перерывов и конвертацией в другой часовой пояс.

## Установка

**Из исходников:**

```bash
git clone <repo>
cd work-timer
go build -o work-timer .
```

**Через go install:**

```bash
go install github.com/Ratatoouille/work-timer@latest
```

**Требования:** Go 1.25+

## Запуск

```bash
work-timer                  # открыть файл за текущую дату (DD_MM.json)
work-timer today.json       # открыть конкретный файл
work-timer --version        # версия
work-timer --help           # помощь
```

При запуске без аргументов автоматически открывается файл `DD_MM.json` (например `04_08.json`) в рабочей папке. Если файла нет — создаётся пустая форма, при сохранении он запишется. Файл в конфиге `default_file` имеет приоритет над автогенерируемым именем.

## Использование

Два режима расчёта:

**Режим 1 — оставшееся время:**

```
Начало:            06:44
Оставшееся время:  09:00
```

→ `15:44`

**Режим 2 — отработано / план:**

```
Начало:     06:44
Отработано: 02:30
План:       09:00
```

→ `13:14` (осталось ещё 6:30)

Заполнять нужно только один из двух режимов.

**Перерывы** добавляются клавишей `a` — каждый вычитается из времени работы, сдвигая конец дня вперёд.

**Конвертация TZ:** если в конфиге задан `timezone`, чекбокс "Показать в TZ" конвертирует результат в нужный пояс.

## Клавиши

### Normal-режим

| Клавиша               | Действие                                           |
| --------------------- | -------------------------------------------------- |
| `j` / `k` / `↑` / `↓` | Навигация по полям                                 |
| `i`                   | Войти в Insert-режим                               |
| `Esc`                 | Выйти в Normal-режим                               |
| `t`                   | Вставить текущее время в поле                      |
| `Space`               | Переключить чекбокс                                |
| `a`                   | Добавить перерыв                                   |
| `d`                   | Удалить текущий перерыв                            |
| `y`                   | Скопировать результат в буфер                      |
| `s`                   | Сохранить (выбор файла)                            |
| `o`                   | Открыть файл из списка                             |
| `/`                   | Поиск файлов в списке                              |
| `d`                   | В списке: удалить файл                             |
| `r`                   | В списке: переименовать файл                       |
| `Ctrl+S`              | Быстрое сохранение (в текущий файл)                |
| `Ctrl+O`              | Открыть список файлов                              |
| `?`                   | Показать / скрыть help                             |
| `q`                   | Выйти (повторно если есть несохранённые изменения) |

### Insert-режим

Вводить текст в формате `чч:мм`. Поле подсвечивается красным при некорректном вводе.

## Конфиг

Создаётся автоматически при первом запуске: `~/.config/work_timer/config.toml`

```toml
# Рабочая папка для сохранений
work_dir = "~/work_timer"

# Открывать этот файл при старте без аргумента
default_file = ""

# Язык интерфейса: "ru" или "en"
language = "ru"

# Часовой пояс ввода (в нём задаётся время начала и перерывов)
input_timezone = "Europe/Moscow"

# Целевой пояс для конвертации результата (оставить пустым = не конвертировать)
timezone = ""   # например "Asia/Krasnoyarsk"

[ui]
label_width = 22   # ширина колонки лейблов

[ui.colors]
# ANSI (0–255) или hex "#RRGGBB"
accent = "12"   # синий    — заголовки, активное поле
result = "14"   # cyan     — результат
break  = "13"   # маджента — секция перерывов
warn   = "11"   # жёлтый  — предупреждения

[ui.timeouts]
clipboard = 2   # секунды до скрытия "скопировано"
status    = 3   # секунды до скрытия статуса сохранения/загрузки
warning   = 4   # секунды до скрытия предупреждений
```

Список IANA timezone: <https://en.wikipedia.org/wiki/List_of_tz_database_time_zones>

## Формат файла сохранения

JSON, создаётся в `work_dir`:

```json
{
  "start_time": "06:44",
  "work_time": "09:00",
  "worked": "",
  "plan": "",
  "add_tz": false,
  "breaks": [{ "from": "12:00", "to": "13:00" }]
}
```
